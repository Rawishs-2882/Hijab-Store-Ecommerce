## Overview

A responsive e-commerce website built for a hijab store, with a MySQL backend for product and order data, deployed on Microsoft Azure so the storefront stays fast and reliable for real customers.

## Key Features

### Responsive storefront
Built with HTML, CSS and JavaScript to work smoothly across desktop and mobile devices.

### MySQL backed catalog
Product listings and orders are stored in MySQL, keeping the storefront's data structured and easy to query.

### Azure deployment
The site is deployed on Microsoft Azure, making it accessible as a real, hosted store rather than a local demo.

HTML5, CSS3 and JavaScript for the frontend, MySQL for the backend database, and Microsoft Azure for hosting and deployment.

## How It Works

The frontend renders product listings and cart interactions in the browser, communicating with a backend that queries MySQL for product and order data. The full stack is deployed on Azure App Service for hosting.

## Setup and Run

1. Import the schema from `/db/schema.sql` into your MySQL instance.
2. Update the database connection settings in `/config`.
3. Serve the site locally with your preferred web server, or deploy directly to Azure App Service.
