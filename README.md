# Hijab-Store-Ecommerce

Responsive e-commerce website for a hijab store, with a MySQL backend, deployed on Microsoft Azure.

## Features
- Responsive HTML/CSS/JavaScript storefront
- MySQL-backed product catalog and orders
- Deployed on Microsoft Azure

## Tech Stack
HTML5, CSS3, JavaScript, MySQL, Microsoft Azure

## Setup & Run
1. Import the schema from `/db/schema.sql` into MySQL.
2. Update DB connection settings in `/config`.
3. Serve the site via your preferred web server or deploy to Azure App Service.
